# Vimla Reference Index v2

## Canonical hierarchy

1. **Foundation references** — theme, color roles, typography, radii, spacing, icon direction.
2. **Component references** — exact component proportions, density and visual states.
3. **Page pattern references** — placement of global areas and responsive composition.
4. **Text specs / i18n / domain contracts** — exact labels, data and behavior.
5. **Backend policy/security** — final authority.
